# Icons Directory

Place your extension icon files here. Chrome requires PNG icons at the following sizes:

| File | Size | Purpose |
|------|------|---------|
| `icon16.png`  | 16×16 px   | Favicon in the toolbar |
| `icon48.png`  | 48×48 px   | Extensions management page |
| `icon128.png` | 128×128 px | Chrome Web Store listing |

## Design Guidelines

- Use a **shield** motif to communicate security and protection.
- Colour palette: cyan (`#00d4ff`) on a dark background (`#0d1117`) to match the extension's cybersecurity theme.
- Keep the design simple and readable at 16×16 px.
- Save as **PNG** with transparency.

## Generating Icons (Free Options)

1. **Favicon.io** — https://favicon.io  
2. **RealFaviconGenerator** — https://realfavicongenerator.net  
3. **Figma / Inkscape** — design a vector and export at the three sizes.

> **Note:** Until real icons are added, Chrome will display a default grey puzzle-piece icon.  
> The extension will still load and function correctly without icon files.
